# 一言 Vela 应用

这是一个为小米手环 Vela 系统开发的一言（Hitokoto）快应用。

## 功能特性

1. **显示一言句子** - 随机展示一句名言/台词
2. **刷新功能** - 点击按钮获取新句子
3. **搜索功能** - 按出处关键词搜索句子（已优化性能）
4. **收藏功能** - 使用 UUID 收藏喜欢的句子

## 项目结构

```
├── src/
│   ├── app.ux              # 应用入口
│   ├── manifest.json       # 应用配置
│   ├── common/

│   │   │   ├── data.js     # 一言数据（需替换为完整数据）
│   │   │   └── logic.js    # 业务逻辑
│   │   └── images/         # 图片资源
│   ├── pages/
│   │   ├── index/          # 主页面
│   │   └── search/         # 搜索页面
│   └── i18n/               # 多语言配置
└── package.json            # 项目配置
```

## 快速开始

### 1. 准备环境

- 安装 Node.js (v14+)
- 安装 HAP Toolkit: `npm install -g hap-toolkit`
- 安装小米 Vela 开发工具

### 2. 安装依赖

```bash
npm install
```

### 3. 添加完整数据

编辑 `src/common/scripts/data.js`，将示例数据替换为你的 7000+ 条完整一言数据。

数据格式：
```javascript
export const hitokotoData = [
  {
    "uuid": "你的 uuid",
    "hitokoto": "句子内容",
    "from": "出处"
  },
  // ... 更多数据
];
```

### 4. 构建运行

```bash
# 开发模式
npm run server

# 构建发布包
npm run release
```

## 使用说明

### 主页面
- 显示随机一言句子和出处
- 刷新按钮：获取新句子
- 收藏按钮：收藏/取消收藏当前句子
- 搜索按钮：跳转到搜索页面
- 收藏列表按钮：查看已收藏数量

### 搜索页面
- 输入出处关键词进行搜索
- 搜索结果列表显示匹配的句子
- 可在搜索结果中直接收藏/取消收藏

## 性能优化

1. **数据索引** - 启动时构建"出处→UUID"映射表，搜索复杂度 O(1)
2. **模块化数据** - 数据存储在独立 JS 模块，避免运行时 JSON 解析
3. **轻量存储** - 收藏仅存储 UUID 数组，节省空间

## 注意事项

1. **数据文件较大** - 7000+ 条数据可能导致文件较大，建议：
   - 确保 JSON 格式正确（无多余逗号）
   - 如遇到内存问题可考虑分页加载

2. **手环屏幕限制** - 当前 UI 针对小屏优化，可根据实际设备调整字体大小和布局

3. **签名配置** - 发布前需在 `sign/` 目录配置证书文件

## 技术栈

- 小米 Vela 快应用框架
- UX 模板语法
- Preferences 持久化存储
